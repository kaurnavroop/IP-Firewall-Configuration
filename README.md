# IP-Firewall-Configuration
# Overview
This project documents my hands-on Security Foundations lab using IPFire, an open-source firewall. I explored firewall administration, processor vulnerability mitigations, URL filtering, and web proxy settings in a controlled learning environment.
# What I worked on
- Accessed and reviewed the IPFire web administration dashboard.
- Examined processor vulnerability mitigation settings.
- Reviewed URL filter categories and configuration options.
- Considered how a web proxy can support network access controls.
- Evaluated potential risks of restrictive filtering and configuration changes.
# What I learned
Firewall settings need to be tested before being applied widely. Blocking too much web traffic can interrupt legitimate work, while an incorrectly configured proxy can cause connectivity problems. Ongoing monitoring and access control are important.
